# TACTIC Docs

Welcome to the Magic Lantern Workbench TACTIC documentation. The documentation is divided into the following books:

- [Quick Start](quick-start/) - get TACTIC, set up your first project and run a workflow
- [Setup](setup/) - configure projects, search types, workflow and access rules
- [System Administration](sys-admin/) - install, deploy, back up and maintain a TACTIC server
- [Developer](developer/) - client API, scripting and development environment
